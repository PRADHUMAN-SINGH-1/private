# Golden-set annotation provenance

The 200-example set is a stratified reference set sampled from AppleSupport response-linked cases. The candidate reviewed the committed labels using the documented annotation policy. `annotation_corrections.csv` tracks any post-review changes.

Sampling target: 20 examples per each of the 10 defined intents. Golden tweet IDs are excluded from the retrieval pool, and the committed quick-evaluation sample does not intentionally reuse golden examples.

The intent/action/must-contain fields are the reference labels used by the evaluation harness.
